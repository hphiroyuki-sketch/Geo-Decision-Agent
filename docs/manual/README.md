## 収録内容

ログイン → ホーム → 調査作成 → **基準地点の指定** → メッシュ解析 → 色の判読 →
公的データ照合 → 報告書のPDF出力、という一本道を STEP 1〜10 で説明し、
加えてスマホでの現地調査、アラート、管理設定、FAQ を収めている。

各画面写真には番号付きの吹き出しを重ね、どこを押すのかを示している。
冒頭に画面遷移図（SVG）があり、全体のどこにいるかが分かる。

## 画面写真の作り方（更新するとき）

写真はローカルの `wrangler dev` に Playwright で接続して撮影した。
再撮影の手順：

1. `npm run build:frontend && npx wrangler d1 migrations apply geo-decision-agent-db --local`
2. `npx wrangler dev`（別プロセスで起動したままにする）
3. ローカルD1に招待コードを1件入れ、`/register` からデモ用アカウントを作る
4. Playwright（`playwright-core` ＋ `/opt/pw-browsers` の Chromium）でログインし、各画面を撮影
5. 1500px 幅・JPEG 品質80 に縮小し、`screenshots/` に置く
6. HTML内の `data:image/jpeg;base64,...` を差し替える

### 既知の制約：地図の中身が写らない

**撮影環境（開発サンドボックス）からは地図タイル配信元に到達できない**ため、
写真では地図が白いままになっている。実際の画面ではここに衛星写真が表示される。
同じ理由で、10mメッシュの色分けオーバーレイも写真には写っていない
（MapLibre の GeoJSON タイル生成がこの環境で完了しないため）。

ガイド本文にはその旨を明記してある。**実機のブラウザで撮った写真が手に入るなら、
地図が写っている数枚を差し替えるのが望ましい。**
