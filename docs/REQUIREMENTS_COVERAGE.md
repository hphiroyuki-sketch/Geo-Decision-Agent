# 要件対応表（v3.0 要件定義書 ⇔ 実装）

判定基準:
- **実装** … 実データで動作し、画面から利用できる
- **部分** … 動作するが、データや範囲に制限がある（制限内容を明記）
- **未実装** … 着手していない（代替手段があれば明記）

「実データ」= Google Earth Engine から実際に取得した値。
「シミュレーション値」= 本MVPが決定論的に生成する仮の値。**画面上で必ず区別表示**している。

## 3. 非機能

| 項目 | 状況 |
|---|---|
| 認証 | 招待制。PBKDF2 + HMAC署名セッション |
| 権限 | 管理者／メンバー／閲覧者 |
| 監査 | `audit_events` に操作履歴 |
| コスト上限 | 月額上限（既定 ¥5,000）到達で自動停止 |
| 稼働監視 | 衛星連携の自己診断（管理設定画面に表示） |
| 実行基盤 | Cloudflare Workers Free（CPU 10ms/リクエスト、外部通信50回/リクエスト）。この制約が10mメッシュのバッチ処理設計の理由 |

## 4. 既知の未確定事項（納品前に確認が必要）

1. **FR-022 衛星指標のクエリ疎通** — NDVI等を1回の呼び出しで取得する式を実装済みだが、
   Earth Engine の関数名が実在するかの最終確認が未完了。管理設定画面の「衛星データ連携の稼働状況」で
   `植生指数（NDVI等）取得` の結果を確認してほしい。失敗していても他機能に影響はない（指標欄が空になるのみ）。
2. **保護区域・急傾斜・流域界などの公的データ未接続** — 現在これらはシミュレーション値。
   実務判断に使う前に、公的データとの照合が必須。
3. **設備台帳（FR-040〜047 / V-07）** — 設備データの提供を受けてから着手する。
4. **地図タイルの商用利用条件** — 現在は国土地理院・Esri・OpenStreetMap の無償タイル。
   商用提供時は各提供元の利用規約確認、または有償プランへの切替が必要。
