# 写真・動画と生物同定の接続設計

2026-09-09。実装済みの範囲と、今後の外部API接続を区別する。

## 現在使えること

現地記録にJPEG・PNG・WebP写真、MP4・WebM動画を1件8MBまで添付し、R2へ保存する。入力された観測日時、サーバー受信日時、座標、端末GPSまたは手入力の区分、GPS精度、メディアのSHA-256を記録する。ハッシュは保存したバイト列の照合用であり、撮影場所・撮影日時の真正性を保証しない。動画は短いクリップ向け。HEIC/MOVや大容量動画は未対応。

地図の基準地点から記録IDでカードを取得する。実際の添付メディアを優先し、デモの6種には出典・ライセンスを付けた参考写真を表示する。参考写真はその場所の観測証拠に数えない。分類情報も入力種名に対応する参考情報であり、画像同定の結果ではない。

## 外部同定APIを接続する際の契約案（未実装）

- 入力: observation_id、media_sha256、認可されたメディア参照、利用同意。希少種の正確な位置は同定に必要な範囲だけ送る。
- 出力: identification_id、provider、model_version、実行日時、候補の学名・分類群ID・候補スコア、処理状態・エラー。動画は抽出フレームと元動画の対応も保存する。
- 同定結果は観測原本を上書きせず、別の履歴として追加する。専門家の承認・訂正者・日時・理由を別に保存し、モデルの候補と確認済みの種を混同しない。
- レッドリスト照合には評価機関、地域、評価年、分類群ID、カテゴリー、出典URLを必須とする。未照合・該当なし・未評価を区別する。
- スコアはモデルが付けた候補スコアであり、正解率ではない。現地の検証データで分類群・撮影条件別に精度を評価してから表示方法を決める。

## 商用利用前に残る条件

同定サービスの選定・契約・送信同意、テナントごとのデータ分離、希少種位置のアクセス制御、媒体保管・削除方針、オフライン同期、監査ログ、現地での精度検証。現状の権限は既存の共通ワークスペースを前提とするため、独立した複数企業の機密情報を同居させる運用はまだ行わない。

衛星埋め込みの類似度だけから種の生息、希少性、生態系の健全性、回復効果を確定する機能は提供しない。衛星で調査候補を絞り、現地記録・専門家レビューを重ねる流れを維持する。
