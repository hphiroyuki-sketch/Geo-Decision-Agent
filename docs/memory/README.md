# 記憶の置き場所（どこに何を残すか）

このプロジェクトは**過去のセッションの記憶に依存しない**。AI でも人でも、
ここから読めば「今どうなっていて、何を決めて、次に何をするか」が分かる状態を保つ。
構造は3層：今の状態（上書き）・時系列（追記のみ）・生の記録（会話）。

| 層 | 置き場所 | 書き方 | 中身 |
|---|---|---|---|
| **今の状態** | [`docs/memory/STATE.md`](STATE.md) | **上書き**（冒頭に最終更新日と理由） | 本番の版、進行中の作業、未決事項、次の一手 |
| **開発の時系列** | [`docs/HISTORY.md`](../HISTORY.md) | **追記のみ** | 何を作ったか、踏んだ不具合とその根本原因 |
| **利用者向けの変更** | [`CHANGELOG.md`](../../CHANGELOG.md) | 版ごとに追記 | 人が読む言葉での変更履歴 |
| **設計判断** | [`docs/DECISIONS.md`](../DECISIONS.md) | ADR を追記 | なぜそう決めたか |
| **会話の全記録（事業の話を含む）** | **Google Drive**：「Geo Decision Agent — 会話と作業の記録」 | 追記のみ。新しいものが下 | 依頼の要旨、やったこと、決めたこと、ユーザーの方針、宿題 |

## なぜ会話記録だけ Google Drive なのか

**このリポジトリは公開（public）で、誰でも読める。**
会話には事業計画、顧客候補、メンターの助言、個人の経歴が含まれるので、リポジトリには置かない（ADR-016）。
リポジトリに残すのは、技術と開発の記録だけ。

## セッションの始め方・終わり方（AI 向け）

**始め**：`CLAUDE.md` → `docs/memory/STATE.md` → 必要なら Drive の会話記録の末尾。
**終わり**：`STATE.md` を上書き、`HISTORY.md`・`CHANGELOG.md` を追記、Drive の会話記録に今回の依頼を1件追記。

## 鍵について

鍵・トークン・パスワード・招待コードの**値**は、どの層にも書かない。名前（`ANTHROPIC_API_KEY` など）だけはよい。
